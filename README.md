# Master Data Structures & Algorithms (DSA) in Python

Welcome to the **Complete DSA Mastery Repository** — a 30-day intensive, pattern-based curriculum designed to transform your problem-solving skills from **Absolute Beginner (Level 1)** to **Interview & Competitive Programming Mastery (Level 9)**.

---

## 🎯 Repository Goal

This repository is built for students and software engineers who say:
> *"I understand the solution when someone explains it, but I struggle to solve unseen problems independently."*

Rather than memorizing solutions to specific LeetCode problems, this curriculum trains your mind to:
1. **Analyze input constraints** to immediately deduce optimal time complexity.
2. **Identify core patterns** from problem statement clues.
3. **Isolate bottlenecks** in brute-force ideas.
4. **Formulate algorithmic invariants** that guarantee correctness.
5. **Implement clean, production-grade Python code** handling all edge cases.

## 📈 The 9-Level Difficulty System

Every problem in this repository is explicitly tagged with one of nine levels:

| Level | Name | Description & Skill Tested | Expected Difficulty |
|---|---|---|---|
| **Level 1** | Absolute Beginner | Direct implementation, basic loops, single array traversal, direct syntax. | Easy |
| **Level 2** | Beginner | Basic patterns: Frequency counting, basic prefix sum, simple 2 pointers. | Easy |
| **Level 3** | Pattern Recognition | Identifying right technique: Hashing vs Two Pointers vs Sliding Window. | Easy → Medium |
| **Level 4** | Intermediate | Combining 2 concepts: Hash map + Prefix sum, Sliding window + Frequency map. | Medium |
| **Level 5** | Strong Intermediate | Deeper reasoning: Monotonic stack, Binary Search on Answer, Graph BFS/DFS. | Medium → Hard |
| **Level 6** | Advanced | Less obvious patterns: Union-Find, Topological Sort, 2D Grid DP, Complex Greedy. | Hard |
| **Level 7** | Expert | Multi-pattern synthesis: DP + Binary Search, Graph + Heap, State Compression. | Hard |
| **Level 8** | Interview / CP | Complex constraints, optimization required, multiple competing approaches. | Hard / Very Hard |
| **Level 9** | Mastery | Mathematical/algorithmic proofs, complex data structure hybrid design. | Very Hard / Expert |

## 🚀 How to Use This Repository

1. **Follow the 30-Day Plan**: Open [`30-day-plan.md`](file:///c:/Users/chakr/Downloads/DSA/30-day-plan.md) and execute daily tasks.
2. **Apply the 7-Step Framework**: When stuck on a problem, open [`problem-solving.md`](file:///c:/Users/chakr/Downloads/DSA/problem-solving.md) instead of looking at the solution.
3. **Follow the Three-Attempt Rule**:
   - *Attempt 1*: 25-30 minutes independent solving.
   - *Attempt 2*: Read Hint 1 and Hint 2 in the problem file.
   - *Attempt 3*: Study the optimal approach and implementation, then re-implement from scratch without looking.
4. **Log Mistakes**: Record every bug, missed edge case, or incorrect pattern choice in [`mistakes.md`](file:///c:/Users/chakr/Downloads/DSA/mistakes.md).
